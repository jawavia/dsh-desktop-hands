# dsh-x2 改造计划（本地自用）

底座：dsh-screen 0.5.2 (MIT) —— 已具备 UIA 优先、控件寻址、sequence 批处理、Unicode 直输、状态条、帧去重。
目标：在本地把它做成**比原版更好用**的自用工具，不发布。

## P0（先做，收益最大）
1. **晶格覆盖层**（我们原来 click-matrix 的招牌）：无 UIA 的窗口（游戏/Chromium 画布）用格点编号点击，避免盲猜坐标。
2. **授权闸门**：默认"未授权不动作"，本地按热键/命令开一个时间窗；动作前校验。原版只有状态条，没有闸门。
3. **图片预算**：每轮最多 N 张/多少 token，超了自动降采样或拒绝截图（我们原版已有逻辑，移植）。

## P1
4. **审计链**：每个动作写一条 hash 链记录（seq/prev/h），本地可验证、防篡改（我们原版已有，移植）。
5. **screen_zoom**：局部放大 + 子格坐标映射（点小目标用）。
6. **多显示器**：虚拟屏范围与每屏 DPI（原版按单屏假设）。

## P2
7. **中文直输增强**：KEYEVENTF_UNICODE 已够用，补一次"长文本分批 + 校验"。
8. **失败回滚**：sequence 中途失败时释放所有按键（我们踩过"鼠标键卡住"）。
9. **配置面板**：预算/热键/settleMs/overlay 开关。

## 不做
- 不发布、不 push、不发群。
- 不复刻原版的"cancelOnEsc 默认关"；授权闸门默认开。
