# 负责任使用与免责声明（Responsible Use）

> 适用版本：dsh-click-matrix v0.8.4 及之后版本
>
> 一句话：**这是给本机、经人类授权的桌面辅助操作工具；不包含跨设备控制、凭据采集或安全机制干预功能。**

## 一、允许的用途

- 在自己的电脑上，辅助完成重复性的桌面操作（整理文件、填表、界面测试等）；
- 在获得明确授权的前提下，操作自己负责的设备或测试环境；
- 软件测试、辅助功能、自动化演示、教学示例；
- 在遵守目标软件服务条款和当地法律的前提下，做有限度的桌面自动化。

所有实际输入动作都必须由**人类在本机授权**（`Ctrl+Alt+F12` 或 `/click-matrix arm`），并可以随时被 `Esc` / `Ctrl+Alt+F11` / STOP 中断。

## 二、使用边界

以下情形不属于本工具的使用范围：

1. 操作不属于你的设备、账号或数据，且未取得设备所有者明确授权；
2. 任何违反所在地法律法规、目标软件服务条款或组织安全政策的用途；
3. 读取、输入、导出他人的凭据、支付信息或隐私数据；
4. 在对方不知情的情况下，把本工具部署到他人的设备上运行。

如果你不确定某个用途是否合适：**先不要做，先问设备所有者/合规负责人。**

## 四、安全设计（默认行为）

- **默认不动**：`mode=ask`，模型不能给自己授权；
- **人类授权**：`Ctrl+Alt+F12` 常开/关，或 `/click-matrix arm <秒|on>`；
- **三层急停**：`Esc`、独立全局 `Ctrl+Alt+F11`、胶囊 STOP / `/click-matrix stop`；
- **暂停与恢复**：真人动鼠标/打字时暂停注入，空闲约 20 秒后只恢复**同一授权**；
- **保护目标**：默认禁止操作 DSH 自身窗口；系统安全界面与需要提权的窗口无法被操作；
- **默认拒绝清单**：安全软件、凭据管理、系统配置类窗口内建为不可操作（见 `lib/policy.js` 的 `DEFAULT_DENY_PROFILES`），由工具层强制执行；
- **本地审计**：动作/拒绝原因写入本地 `audit.jsonl`，不含任何联网上报组件；
- **本地 helper**：从源码在本机编译，没有预编译二进制。

这些设计用于降低误操作与模型误用风险，但**不能阻止使用者修改源码**。
